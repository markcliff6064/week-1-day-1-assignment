# HTML Fundamentals Practice

This repository contains three beginner HTML projects created to practice the fundamentals of **HTML5, semantic structure, links, lists, and tables**.

## Projects

### 1. Personal Business Card

A simple personal profile page containing my name, professional title, contact information, location, social media profiles, and technical skills. It uses semantic elements such as `<header>`, `<main>`, `<section>`, `<nav>`, `<address>`, and `<footer>`.

### 2. Weekly Class Schedule

A structured weekly timetable created using an HTML table. It demonstrates the use of `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`, including `colspan` to represent a class spanning multiple columns.
